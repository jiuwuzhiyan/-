# 团购数据采集工具 - 需求文档

## 目标

开发一个可以从抖音、美团平台获取指定商圈团购店铺、套餐内容、价格、销量、评分、用户评价等数据的工具，提供友好的网页界面，支持多种数据获取方式和存储导出格式。

## 范围

本工具涵盖以下功能范围：
- 抖音和美团双平台数据采集
- 店铺基本信息采集
- 套餐详情采集
- 用户评价采集
- 手动和定时数据获取
- 多种数据存储和导出格式
- Web 用户界面

## 功能要求

### 1. 平台数据采集

#### 抖音平台
- 支持输入商圈信息定位目标区域
- 自动访问抖音团购页面
- 采集店铺列表信息（名称、地址、评分、销量等）
- 采集店铺套餐详情（名称、描述、价格、销量）
- 采集用户评价内容

#### 美团平台
- 支持输入商圈信息定位目标区域
- 自动访问美团团购页面
- 采集店铺列表信息（名称、地址、评分、销量等）
- 采集店铺套餐详情（名称、描述、价格、销量）
- 采集用户评价内容

### 2. 数据获取方式

#### 手动触发
- 用户通过界面点击触发数据采集
- 显示采集进度和状态
- 支持暂停和取消采集任务

#### 定时自动获取
- 支持配置定时任务
- 可设置采集频率和时间
- 自动执行采集任务并记录日志

### 3. 数据存储与导出

#### 数据库存储
- 使用 SQLite 存储采集的数据
- 支持数据查询和筛选
- 保留历史数据版本

#### 文件导出
- 支持导出为 Excel 格式（.xlsx）
- 支持导出为 CSV 格式
- 支持导出为 JSON 格式

### 4. 用户界面

#### 主界面
- 平台选择（抖音/美团/双平台）
- 商圈信息输入
- 采集参数配置
- 任务控制按钮

#### 数据展示
- 店铺列表展示
- 套餐详情展示
- 用户评价展示
- 数据筛选和搜索

#### 任务管理
- 任务列表展示
- 任务状态跟踪
- 历史任务记录

#### 导出功能
- 导出格式选择
- 导出范围配置
- 文件下载

## 验收标准

当用户选择抖音平台并输入商圈信息时，系统应能采集该商圈的团购店铺数据。

当用户选择美团平台并输入商圈信息时，系统应能采集该商圈的团购店铺数据。

当用户选择要采集的店铺时，系统应能获取该店铺的套餐内容、价格、销量、评分和用户评价。

当用户需要获取数据时，系统应支持手动触发和定时自动触发两种方式。

当数据采集完成后，系统应支持将数据存储到数据库，并可导出为Excel/CSV或JSON格式。

当用户访问工具时，系统应提供直观友好的网页界面供操作。
