# 团购数据采集工具 - 设计文档

## 设计目标

设计一个高效、稳定、易用的团购数据采集工具，具备以下特点：
- 良好的用户体验，界面简洁直观
- 稳定的数据采集能力，能应对反爬虫机制
- 灵活的数据存储和导出功能
- 可扩展的架构设计
- 完善的错误处理和日志记录

## 技术栈

### 后端
- **运行时**: Node.js
- **Web框架**: Express.js
- **浏览器自动化**: Playwright
- **数据库**: SQLite3
- **定时任务**: node-cron
- **Excel处理**: exceljs
- **任务队列**: Bull

### 前端
- **框架**: React 18
- **UI组件库**: Ant Design
- **状态管理**: Redux Toolkit
- **HTTP客户端**: Axios
- **路由**: React Router

## 模块划分

### 1. 数据采集模块

#### 抖音采集器 (DouyinScraper)
- 使用 Playwright 启动浏览器
- 导航到抖音团购页面
- 模拟用户搜索商圈
- 解析店铺列表 DOM 结构
- 提取店铺基本信息
- 进入店铺详情页
- 解析套餐信息
- 滚动加载用户评价
- 解析评价内容

#### 美团采集器 (MeituanScraper)
- 使用 Playwright 启动浏览器
- 导航到美团团购页面
- 模拟用户搜索商圈
- 解析店铺列表 DOM 结构
- 提取店铺基本信息
- 进入店铺详情页
- 解析套餐信息
- 滚动加载用户评价
- 解析评价内容

### 2. 数据存储模块

#### 数据库模型
- **店铺表 (shops)**: 存储店铺基本信息
- **套餐表 (packages)**: 存储套餐详情
- **评价表 (reviews)**: 存储用户评价
- **任务表 (tasks)**: 存储采集任务记录

#### 数据库操作
- 数据插入和更新
- 批量数据操作
- 数据查询和筛选
- 事务处理

### 3. 任务调度模块

#### 任务管理器
- 手动任务触发
- 任务队列管理
- 任务状态跟踪
- 任务进度反馈

#### 定时任务
- Cron 表达式解析
- 定时任务注册
- 任务执行日志
- 异常处理和重试

### 4. 导出模块

#### Excel/CSV 导出
- 使用 exceljs 生成工作簿
- 多工作表支持
- 数据格式化
- 文件流式下载

#### JSON 导出
- 数据序列化
- 格式化输出
- 文件下载

### 5. API 接口模块

#### RESTful API
- 任务管理接口
- 数据查询接口
- 数据导出接口
- 配置管理接口

#### WebSocket
- 实时任务进度推送
- 状态变更通知

### 6. 前端模块

#### 页面组件
- 主页面：平台选择、商圈输入、任务控制
- 数据展示页：店铺列表、套餐详情、用户评价
- 任务管理页：任务列表、历史记录
- 配置页：定时任务配置、系统设置

#### 状态管理
- 任务状态
- 采集数据
- 用户配置

#### 交互设计
- 加载状态提示
- 进度条展示
- 错误提示
- 成功反馈
