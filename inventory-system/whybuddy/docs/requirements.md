# 需求规格说明书

## 目标

重新设计唐山中骏世界城库存管理系统，采用深色科技风格UI，打造专业、大气、高级感的企业级物资出入库管理平台。保留现有核心业务功能（出入库流程、审批流程、库存管理、用户权限），全面升级用户界面体验。

## 范围

### 适用对象
- 唐山中骏世界城物资管理人员
- 财务审批人员
- 行政管理人员
- 系统运维人员

### 系统边界
- **包含**：用户管理、物资管理、入库管理、出库管理、回库管理、审批管理、库存管理、报表管理
- **不包含**：供应链上游系统、财务记账系统

## 功能要求

### 1. 多角色权限管理

当系统管理员配置用户角色时，系统应支持以下四种角色：

| 角色 | 核心权限 |
|------|----------|
| 系统管理员 | 用户管理、角色配置、物资管理、所有审批权限、数据导出、打印 |
| 业务人员 | 录入入库/出库/回库单据、查看所有单据、查看库存统计、数据导出、打印 |
| 财务人员 | 审批入库/出库/回库单据、查看所有单据、查看库存统计、数据导出、打印 |
| 行政人员 | 审批入库/出库/回库单据、查看所有单据、查看库存统计、数据导出、打印 |

### 2. 入库管理

当业务人员提交入库单时，系统应：
- 支持单个物资录入和批量导入（Excel模板）
- 记录物资明细：名称、规格、到期日、单位、数量、单价
- 提交后进入并行审批流程
- 审批通过后自动增加库存

### 3. 出库管理

当业务人员提交出库单时，系统应：
- 支持单个物资录入和批量导入
- 选择物资并填写出库数量
- 提交后进入并行审批流程
- 审批通过后自动减少库存

### 4. 回库管理

当业务人员提交回库单时，系统应：
- 关联原出库单
- 选择需要回库的物资及数量
- 提交后进入并行审批流程（与入库/出库一致）
- 审批通过后自动增加库存

### 5. 并行审批流程

当业务人员提交单据（入库/出库/回库）时，财务人员和行政人员应能同时进行审批：
- 双方可独立决定通过或驳回
- 双方都通过后单据生效
- 任意一方驳回则整体驳回，需填写驳回原因
- 审批进度实时显示

### 6. 库存管理

当用户查询库存时，系统应：
- 显示所有物资的实时库存数量
- 支持按名称、规格等条件筛选
- 提供库存统计和可视化图表

### 7. 报表与数据导出

当用户需要导出数据时，系统应：
- 支持按时间、单据状态、物资名称、操作人筛选
- 导出为Excel格式（.xlsx/.xls）
- 提供标准模板下载

### 8. 单据打印

当用户打印单据时，系统应：
- 生成规范化的打印格式
- 包含单据基本信息、物资明细、审批记录
- 支持打印预览

## 验收标准

### 核心功能验收

| 验收项 | 验收标准（EARS句式） |
|--------|---------------------|
| VA-1 | 当用户访问登录页时，系统应显示深色科技风格的登录界面 |
| VA-2 | 当管理员配置角色权限时，系统应支持业务/财务/行政/管理员四种角色 |
| VA-3 | 当业务人员提交入库单时，财务和行政应能同时进行审批 |
| VA-4 | 当财务和行政都审批通过时，系统应自动增加对应物资的库存 |
| VA-5 | 当用户点击导出按钮时，系统应生成.xlsx格式的Excel文件 |
| VA-6 | 当用户点击打印按钮时，系统应显示规范的打印预览 |
| VA-7 | 当用户操作系统时，页面响应时间应小于2秒 |

### UI设计验收

| 验收项 | 验收标准 |
|--------|----------|
| UI-1 | 主色调为深蓝黑色（#0a0e17），体现沉稳专业感 |
| UI-2 | 强调色为科技蓝（#1890ff）或渐变紫色（#667eea） |
| UI-3 | 卡片组件采用半透明玻璃态效果 |
| UI-4 | 按钮具有渐变色和微光效果 |
| UI-5 | 表格具有斑马纹和悬浮高亮效果 |
| UI-6 | 图表具有发光效果 |
