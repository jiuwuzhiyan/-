# 设计规格说明书

## 设计目标

打造深色科技风格的库存管理系统，通过沉稳深邃的配色、精致的光效层次、流畅的动效交互，体现专业、大气、高级感的企业级产品气质。

## 设计原则

1. **沉稳专业**：深色基调传递稳重可靠的品质感
2. **科技感**：蓝色/紫色渐变点缀，网格/粒子动效增强现代感
3. **层次分明**：通过透明度、阴影、光晕构建视觉层次
4. **交互愉悦**：微动效提升体验流畅度
5. **功能优先**：设计服务于业务，不为炫技而设计

## 模块划分

### 1. 登录模块

**设计要点**：
- 全屏深色背景，可添加动态网格或粒子效果
- 居中玻璃态登录卡片（毛玻璃效果）
- 顶部品牌LOGO和系统名称
- 表单包含用户名、密码、角色选择
- 按钮采用渐变色+微光效果

**交互细节**：
- 输入框获焦时边框发光（科技蓝）
- 登录按钮hover时微光扩散
- 加载状态显示发光脉冲动画

### 2. 仪表盘模块

**设计要点**：
- 顶部统计卡片网格（4列布局）
- 统计卡片：今日入库、今日出库、待审批、库存总量
- 卡片采用深色半透明玻璃态
- 数字采用大号等宽字体
- 图表区域：入库趋势图、物资分类饼图
- 右侧快捷操作入口列表

**交互细节**：
- 卡片hover时轻微上浮+阴影加深
- 图表加载时渐显动画

### 3. 单据管理模块（入库/出库/回库）

**设计要点**：
- 左侧筛选条件栏（可折叠）
- 中间单据列表表格
- 右侧单据详情面板（可滑出）
- 表格列：单据编号、类型、提交人、时间、状态、操作
- 状态标签采用渐变色（待审批：橙→蓝渐变，已通过：绿，已驳回：红）

**交互细节**：
- 表格行hover高亮
- 分页采用滚动加载更多
- 新建单据弹窗表单

### 4. 审批模块

**设计要点**：
- 审批进度时间轴（顶部）
- 双栏并行审批卡片（财务/行政）
- 每栏显示审批人、审批状态、审批时间、意见
- 当前待审批项高亮脉冲
- 审批意见气泡框

**交互细节**：
- 审批按钮通过/驳回
- 驳回需填写原因（弹出输入框）
- 通过后卡片变绿+打勾动画

### 5. 库存模块

**设计要点**：
- 搜索栏+筛选条件
- 物资卡片网格/列表切换视图
- 卡片显示：物资名称、规格、当前库存
- 库存柱状图可视化

### 6. 用户管理模块

**设计要点**：
- 用户列表表格
- 角色权限矩阵表格
- 新建/编辑用户弹窗
- 角色颜色标签

## 组件设计

### 按钮组件

| 类型 | 样式 |
|------|------|
| 主按钮 | 渐变蓝（#1890ff→#667eea），白色文字，hover发光 |
| 次按钮 | 透明背景，蓝色边框，蓝色文字 |
| 危险按钮 | 渐变红（#ff4d4f→#ff7875），白色文字 |
| 禁用状态 | 灰色背景，50%透明度文字 |

### 卡片组件

- 背景：rgba(17, 24, 39, 0.8) 半透明
- 边框：1px solid #2d3748
- 阴影：0 4px 24px rgba(0, 0, 0, 0.4)
- hover：translateY(-2px)，阴影加深

### 表格组件

- 表头：#111827 背景，白色文字
- 斑马纹：奇数行 #0a0e17，偶数行 #111827
- hover：行的背景变亮
- 选中：左侧蓝色边框指示

### 标签/徽章

| 状态 | 样式 |
|------|------|
| 待审批 | 橙色渐变背景 |
| 已通过 | 绿色背景 |
| 已驳回 | 红色背景 |
| 草稿 | 灰色背景 |

### 表单输入

- 背景：rgba(17, 24, 39, 0.6)
- 边框：#2d3748
- 获焦：边框变为科技蓝+发光

## 动效规范

| 动效类型 | 参数 | 说明 |
|----------|------|------|
| 渐显 | opacity 0→1, 300ms ease-out | 页面/卡片进入 |
| 上浮 | translateY 8px→0, 300ms ease-out | hover效果 |
| 发光 | box-shadow渐变, 1s infinite | 按钮hover |
| 脉冲 | scale 1→1.05→1, 1.5s infinite | 强调数字 |
| 滑入 | translateX 100%→0, 300ms ease-out | 侧边面板 |

## 失败处理策略

### 加载状态
- 骨架屏占位，保持布局稳定
- 不显示空白区域

### 错误状态
- 红色警告卡片展示错误信息
- 提供重试按钮
- 错误不影响其他正常区域

### 空状态
- 友好的空状态插图
- 引导用户进行操作

### 网络异常
- 顶部toast提示
- 自动重试机制
- 离线时显示缓存数据
