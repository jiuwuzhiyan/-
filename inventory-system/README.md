# 唐山中骏世界城库存系统

一个支持多角色权限、并行审批流程的企业物资出入库管理系统，实现入库、出库、回库全流程数字化管理。

## 功能特性

- **多角色权限管理**：业务人员、财务人员、行政人员、系统管理员
- **并行审批流程**：财务和行政同时审批，双方都通过后单据生效
- **完整的物资管理**：入库、出库、回库全流程覆盖
- **实时库存查询**：支持库存预警功能
- **数据导出**：支持导出 Excel 报表

## 技术栈

- **前端**：React 18 + Ant Design 5.x + Vite + TypeScript
- **后端**：Node.js + Express.js
- **数据库**：SQLite 3
- **身份认证**：JWT + bcrypt

## 快速开始

### 1. 安装依赖

```bash
# 一键安装所有依赖
npm run install:all
```

或者分步安装：

```bash
# 安装根目录依赖
npm install

# 安装前端依赖
cd client
npm install

# 安装后端依赖
cd ../server
npm install
```

### 2. 启动项目

#### 方式一：使用批处理文件（Windows）

直接双击项目根目录下的 `start.bat` 文件即可一键启动前后端服务。

#### 方式二：使用 npm 命令（推荐）

```bash
# 在项目根目录运行
npm run dev
```

这将同时启动：
- 后端服务（端口 3000）
- 前端服务（端口 5173）

#### 方式三：分别启动

```bash
# 启动后端
npm run dev:server

# 启动前端（新开终端
npm run dev:client
```

### 3. 访问系统

打开浏览器访问：http://localhost:5173

## 角色权限

### 业务人员
- 录入入库单、出库单、回库单
- 查看自己提交的单据
- 查看库存
- 查看出入库记录

### 财务人员
- 审批入库单、出库单
- 查看所有单据
- 查看库存统计
- 导出报表

### 行政人员
- 审批入库单、出库单
- 查看所有单据
- 查看库存统计
- 导出报表

### 系统管理员
- 管理用户账号
- 分配角色权限
- 所有财务和行政权限

## 业务流程

### 入库流程
1. 业务人员录入入库单
2. 提交单据进入审批流程
3. 财务和行政同时审批（并行）
4. 双方都通过后自动增加库存

### 出库流程
1. 业务人员录入出库单
2. 提交单据进入审批流程
3. 财务和行政同时审批（并行）
4. 双方都通过后自动减少库存

### 回库流程
1. 业务人员录入回库单（关联原出库单）
2. 无需审批，提交后自动增加库存

## 数据库

SQLite 数据库文件位于 `server/database.db`，首次启动时会自动创建并初始化测试数据。

## 注意事项

- 首次启动会自动创建超级管理员账号（admin/123456）
- 前端开发服务器代理 API 请求到后端（/api -> localhost:3000）
- JWT 令牌有效期为 7 天
- 密码使用 bcrypt 加密存储
