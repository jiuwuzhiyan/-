# 唐山中骏世界城库存系统

一个支持多角色权限、并行审批流程的企业物资出入库管理系统，实现入库、出库、回库全流程数字化管理。

## 功能特性

### 核心功能

- **多角色权限管理**：支持业务人员、财务人员、行政人员、系统管理员四种角色
- **并行审批流程**：财务和行政可同时审批单据，双方都通过后单据生效
- **完整的物资管理**：入库、出库、回库全流程覆盖，支持物资基础信息维护
- **实时库存查询**：支持库存预警功能，实时掌握库存状态
- **数据导出**：支持导出 Excel 报表

### 物资管理

- 物资信息维护（名称、规格、到期日、单位、单价等）
- 实时库存数量查询
- 库存预警提示

### 单据管理

- **入库单**：支持单个录入和批量导入，提供 Excel 模板下载
- **出库单**：支持单个录入和批量导入，提供 Excel 模板下载
- **回库单**：支持单个录入和批量导入，提供 Excel 模板下载
- 单据状态跟踪（草稿、待审批、已通过、已驳回）
- 单据打印功能

### 审批流程

- 业务人员提交单据后进入审批流程
- 财务和行政并行审批
- 审批进度实时显示
- 支持驳回并填写驳回原因

### 报表功能

- 出入库记录查询与导出
- 按时间、单据状态、物资名称、操作人筛选
- Excel 格式导出

## 技术栈

- **前端**：React 18 + Ant Design 5.x + Vite + TypeScript
- **后端**：Node.js + Express.js
- **数据库**：SQLite 3（使用 sql.js）
- **身份认证**：JWT + bcrypt
- **Excel处理**：xlsx

## 快速开始

### 1. 安装依赖

```bash
# 一键安装所有依赖
npm run install:all
```

或者分步安装：

```bash
# 安装根目录依赖
npm install

# 安装前端依赖
cd client
npm install

# 安装后端依赖
cd ../server
npm install
```

### 2. 启动项目

#### 方式一：使用批处理文件（Windows）

直接双击项目根目录下的 `start.bat` 文件即可一键启动前后端服务。

#### 方式二：使用 npm 命令（推荐）

```bash
# 在项目根目录运行
npm run dev
```

这将同时启动：
- 后端服务（端口 3000）
- 前端服务（端口 5173）

#### 方式三：分别启动

```bash
# 启动后端
npm run server

# 启动前端（新开终端）
npm run client
```

### 3. 访问系统

打开浏览器访问：http://localhost:5173

- 查看所有单据

### 行政人员

- 审批入库单、出库单

- 查看库存统计
- 导出报表

### 系统管理员

- 管理用户账号
- 分配角色权限
- 编辑物资信息
- 所有财务和行政权限

## 业务流程

### 入库流程

1. 业务人员录入入库单（单个录入或批量导入）
2. 填写物资明细（物资名称、规格、到期日、单位、数量、单价等）
3. 提交单据进入审批流程
4. 财务和行政同时审批（并行）
5. 双方都通过后自动增加库存

### 出库流程

1. 业务人员录入出库单（单个录入或批量导入）
2. 选择物资并填写数量
3. 提交单据进入审批流程
4. 财务和行政同时审批（并行）
5. 双方都通过后自动减少库存

### 回库流程

1. 业务人员录入回库单（关联原出库单）
2. 选择需要回库的物资
3. 无需审批，提交后自动增加库存

### 批量导入说明

系统支持 Excel 批量导入功能：

1. 点击「下载模板」按钮获取 Excel 模板
2. 按照模板格式填写物资信息
3. 点击「批量导入」选择填好的 Excel 文件
4. 系统会自动解析并填充物资明细

## 数据库

SQLite 数据库文件位于 `server/database.db`，首次启动时会自动创建并初始化测试数据。

### 数据表结构

- **users**：用户信息
- **materials**：物资基础信息
- **inbound_orders / inbound_items**：入库单及明细
- **outbound_orders / outbound_items**：出库单及明细
- **return_orders / return_items**：回库单及明细
- **stock_records**：库存变动记录

## 注意事项

- 首次启动会自动创建超级管理员账号（admin/123456）
- 前端开发服务器代理 API 请求到后端（/api -> localhost:3000）
- JWT 令牌有效期为 7 天
- 密码使用 bcrypt 加密存储
- 批量导入支持 .xlsx 和 .xls 格式
- 所有单据审批通过后才会更新库存
